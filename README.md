# Smart Mobs AI

Smart Mobs AI is a Minecraft Fabric mod focused on expanding mob behavior, interactions, reactions, combat and AI systems.

The goal of the project is to make Minecraft mobs feel more dynamic and reactive while keeping their behavior integrated with the vanilla game.

## Features

- Expanded mob AI and behavior
- New combat behaviors and reactions
- More dynamic mob interactions
- Additional AI goals
- Improved mob responses to players and other mobs
- Custom mob messages and reactions
- Piglin interaction and trading improvements
- New gameplay mechanics built around mob behavior
- Configurable client features
- Russian and English localization

## Supported Version

- Minecraft: **1.20.1**
- Mod Loader: **Fabric**
- Java: **17**

## Development

The repository contains the source code and Gradle project required to build the mod.

### Requirements

- Java 17
- Minecraft 1.20.1
- Fabric development environment

### Build

Clone the repository and run:

```bash
./gradlew build
```

On Windows:

```bat
gradlew.bat build
```

The compiled JAR will be generated in:

```text
build/libs/
```
